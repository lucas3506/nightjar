Status badges

On Pro and Scale plans, any check can publish an SVG badge showing passing, failing, waiting or paused. Turn on Public badge in the check’s settings and copy the Markdown snippet:

![nightly-backup](https://wzbetaadovfmwgqfspcw.supabase.co/functions/v1/badge/YOUR_BADGE_KEY.svg)

The badge URL uses a separate key from the ping URL, so publishing a badge never exposes the URL that controls the check. Badges are cached for 60 seconds. Turning the badge off, or downgrading to Hobby, makes the URL return an “unavailable” badge.
