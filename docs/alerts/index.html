Concepts

Alert channels

Add channels on the Alert channels page. Every enabled channel receives every alert for your checks, so you can send everything to Slack and also get phone notifications through ntfy. Use Send test to confirm delivery. The delivery log shows the HTTP status each service returned.

Slack

In Slack, create an app with Incoming Webhooks enabled (or use the legacy Incoming WebHooks integration), pick a channel, and paste the https://hooks.slack.com/services/… URL.

Discord

Open Server settings → Integrations → Webhooks → New webhook, choose a channel and copy the webhook URL.

Telegram

  1. Talk to @BotFather, send /newbot, and copy the bot token.
  2. Add the bot to your group or channel, send it a message, and find the chat ID. For a channel, use @channelname.
  3. Paste the token and chat ID into Nightjar.

ntfy (phone push)

Install the ntfy app on iOS or Android and subscribe to a topic name that is hard to guess (for example nightjar-7f2kq9). Enter the same topic in Nightjar. Self-hosted ntfy servers and access tokens are supported.

Google Chat

In a space, open Apps & integrations → Webhooks, add one, and paste the https://chat.googleapis.com/… URL.

Webhooks

Nightjar POSTs JSON to any public HTTPS URL:

{
  "event": "down",
  "summary": "DOWN · nightly-backup",
  "message": "Expected a ping by Nov 04, 02:00 Europe/Berlin (+10m grace). Last ping: Nov 03, 02:04 Europe/Berlin.",
  "log": null,
  "url": "https://lucas3506.github.io/nightjar/app/checks/…",
  "monitor_id": "8b7c…",
  "sent_at": "2026-11-04T01:10:00Z"
}

event is one of down, fail, up, slow, hung or test. If you set a secret, it’s sent in the X-Nightjar-Secret header so your endpoint can reject other callers. Private and internal addresses are not allowed.

Alert types

EventWhen
downA ping is overdue past the grace period
failThe job reported a failure (/fail or a non-zero exit code)
upA failing or late check received a successful ping
slowA run took longer than the check’s maximum duration (Pro)
hungA run started and didn’t finish within the maximum duration (Pro)
