Ping API

Every check has one URL. Append a suffix to send a different signal. All endpoints accept GET, POST, PUT and HEAD, need no authentication beyond the token in the URL, and return 200 OK as plain text.

RequestMeaning
/ping/<token>Success. The check is up, and the next expected time is recalculated.
/ping/<token>/startThe job has started. Used to measure duration and detect stuck runs.
/ping/<token>/failThe job failed. The check goes down and an alert is sent.
/ping/<token>/<0-255>Exit status. 0 is success; anything else is a failure with that exit code.
/ping/<token>/logAttach a log entry without changing the check’s state.

Base URL: https://wzbetaadovfmwgqfspcw.supabase.co/functions/v1/ping

Sending output

Send the job’s output as the request body of any POST or PUT. Nightjar keeps the end of the body (2 KB on Hobby, 32 KB on Pro, 128 KB on Scale), shows it in the run history, and includes it in failure alerts.

tail -n 50 /var/log/backup.log | curl -fsS -m 10 --data-binary @- https://wzbetaadovfmwgqfspcw.supabase.co/functions/v1/ping/YOUR_TOKEN/1

Measuring duration

Ping /start before the work and a success or failure ping after it. Nightjar records the time in between as the run’s duration.

curl -fsS -m 10 https://wzbetaadovfmwgqfspcw.supabase.co/functions/v1/ping/YOUR_TOKEN/start
./long-job.sh
curl -fsS -m 10 https://wzbetaadovfmwgqfspcw.supabase.co/functions/v1/ping/YOUR_TOKEN/$?

On Pro and Scale, set a maximum duration on the check:

  • If a run finishes but took longer than the maximum, you get a slow run alert.
  • If a run started and hasn’t finished within the maximum, you get a stuck alert while it is still running.

A /start older than 24 hours isn’t paired with a later success, so a forgotten start signal can’t produce nonsense durations.

Responses

StatusBodyMeaning
200OKPing recorded.
400usage textMalformed token or unknown suffix.
404Not foundNo check uses this token (deleted, or the URL was rotated).
429Rate limitedMore than 120 pings per minute for one check.
503Temporary errorRetry. curl --retry 5 handles this for you.

Paused checks

Pings to a paused check are recorded in its history, but they don’t change its state or send alerts. Resume the check from the dashboard.

Rotating a URL

If a ping URL leaks, open the check, choose Rotate URL, and update your job. The old URL stops working immediately.
